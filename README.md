# 311BANCHI 請求書・freee会計連携

請求管理台帳に登録した請求書をfreee会計の売上取引として登録し、freee会計で入金消込された状態を台帳へ同期する、Windows向けのローカル実行版です。

## 必要なもの

- Windows
- Node.js 18以降
- freee会計のAPIアプリ（Client ID / Client Secret）

## 起動

1. このフォルダーに `.env.example` をコピーし、コピーを `.env` に名前変更します。
2. `.env` の Client ID と Client Secret を入力します。Redirect URI は次の値をそのまま設定します。
   `http://127.0.0.1:8787/oauth/callback`
3. このフォルダーでターミナルを開き、`npm start` を実行します。
4. ブラウザーで `http://127.0.0.1:8787` を開きます。
5. アプリの「freeeに接続」を押し、freeeの許可画面で連携を許可します。
6. 事業所・売上高などの勘定科目・税区分を選び、「設定を保存」します。
7. 請求書を登録すると、freee会計に未入金の売上取引を登録します。
8. freee会計で銀行明細を取り込み、該当取引の入金消込を行うと、アプリ台帳の入金状態も同期されます。

## 同期について

- freeeとの接続トークンと設定は `.data` に保存されます。このフォルダーを公開リポジトリへアップロードしないでください。
- `.env` と `.data/` は `.gitignore` で除外しています。Client SecretをHTMLやGitHubへ書かないでください。
- 同期はこのPCでサーバーが起動している間に5分ごとに行います。アプリを開き直したときにも状態を再取得します。
- 台帳データはブラウザーのローカル保存領域に残ります。定期的に「バックアップ保存 (JSON)」を使ってください。
- freee会計側に同じ請求書番号がある場合は、二重登録を避けるため登録を止めます。
- freeeへの接続や初回登録はfreeeの事業所、勘定科目、税区分を選んでから行ってください。

## 重要

このローカル版はGitHub Pages上ではfreee APIを呼びません。必ずNode.jsサーバーを起動し、上記の `http://127.0.0.1:8787` からアプリを使います。

## クラウド公開の準備（Render）

`render.yaml` はRenderの設定案です。まだサービスを作成・公開しません。クラウドで動かすにはRenderアカウントで設定を確認し、有料サービスを作成する必要があります。

- `starter` Web Service と 1 GB の永続ディスクを使います。Renderの現在の表示ではWeb Serviceは月7米ドルから、ディスクは1 GBあたり月0.25米ドルです。税・為替・追加利用料は別途確認してください。
- 無料Web Serviceはアイドル時に停止し、ディスクも使えないため、このアプリの定期同期とfreeeトークンの保存には使いません。
- Renderの環境変数に `APP_PASSWORD`（16文字以上）、freeeアプリの `FREEE_CLIENT_ID` と `FREEE_CLIENT_SECRET` を安全に登録します。値をGitHubやこのREADMEに書かないでください。
- Renderが発行したHTTPS URLの `/oauth/callback` をfreee開発者アプリのRedirect URIにも登録します。クラウド側ではこのHTTPS URLを使用します。
- 公開前にローカル版の「freee同期情報を保存」で設定を保存します（OAuthトークンは含めません）。クラウド版では台帳JSONを読み込み、freeeへ再接続した後で「freeeの入金状況を今すぐ同期」を押します。請求書番号がfreeeの取引番号と一致する既存取引を照合して、クラウド側に同期IDを登録します。
- 請求書・見積・取引先の台帳はブラウザーごとの保存です。「バックアップ保存 (JSON)」で保存し、クラウドURLを開いたブラウザーで「バックアップ読込」してください。クラウドサーバーはfreee入金状態を5分ごとに確認し、アプリを開いた時に台帳へ反映します。
- `.data/` の `token.json` はOAuthトークンです。公開リポジトリ、画面共有、チャットへ絶対に送らないでください。
